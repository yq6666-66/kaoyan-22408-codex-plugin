# 408考研插件

`kaoyan-408` 是面向考研 408 方向的中文 **Skills-only** 学习插件，运行在 Codex 与 ChatGPT 中，覆盖**数学一、数学二、英语一、英语二、408 与政治**。插件提供五类真题（2010—2026）的合规检索与分析、新手图文讲解、学习规划与执行、进度诊断、错题闭环、原创模考、官方招考信息核验，并可条件式连接 14 个学习层（Obsidian / Notion / Udemy / Sider Scholar / Exa / GoodNotes / Wolfram / A-Z Dictionary / Quizlet / Ace Quiz Maker / Ace Knowledge Graph / AhaMotion / Vocabulary Trainer / Kahoot）。

当前版本：`2.3.0`

项目没有 App、MCP、后台服务、云端题库、账号或 API Key。网页搜索、图片生成、各学习层和本地文件能力由当前 ChatGPT/Codex 宿主决定；未连接或权限不足时插件明确降级，不伪造搜索结果或学习记录。

## 功能总览

### 真题搜索与核验

- 固定检索范围：2010—2026 年**数学一、数学二、英语一、英语二、408** 五类试卷。
- 普通网页发现与 `site:github.com` 定向检索并行；只有实际访问到结果才标记来源渠道。
- 官方来源优先；GitHub 来源记录仓库、文件、commit、许可与原始 URL。
- 去重键为「科目 + 试卷年度 + 试卷类型 + 题号 + 内容哈希」，同时保存 `paperYear` 与 `examDate`。
- 许可证不明时只保存索引与必要短摘录；只有官方明确允许或开放许可证覆盖时才保存全文。
- 搜索关闭时输出 `[真题未命中]` 与可复制的搜索式，不伪造结果。

### 新手图文讲解

单题解析统一按以下结构输出：

1. 结论与题型定位；
2. `[真题证据]`（科目、试卷年度、实际考试日期、题号、来源 URL、核验状态）；
3. 前置知识清单；
4. 可编辑图解（Mermaid / 表格 / SVG）；
5. 逐步推导，每一步解释“为什么”；
6. 独立复核（换方法或边界条件）；
7. 第一处易错点与常见误区；
8. `[原创练习]` 迁移题（不冒充真题）；
9. 学习层写回与必要的 Schema 1.1 便携记录。

没有可靠真题时输出 `[真题未命中]` 并用 `[原创示例]` 完成教学，不编造年份、题号或答案。

### 学习闭环

- **规划**：阶段、月度、周度、目标日期倒排与跨科配额。
- **执行**：把计划或本次目标展开为立即可做的时间盒。
- **诊断**：根据真实记录识别进度偏差、风险与调整信号。
- **错题闭环**：跨题错因聚类、间隔复测、延迟掌握证据判断。
- **模考**：原创或用户授权题目的冻结题面模考，交卷前零泄露，交卷后按公开 rubric 评分。
- **便携记录**：`StudyProfile` / `ProgressSnapshot` / `ReviewQueue` 均输出 Schema 1.1 JSON，可跨会话粘贴回传。

### 官方信息核验

- 当年大纲、报名、考试安排只以教育部、研招网、省级教育考试院、报考点及政府机构官网为准。
- 支持“用户指定 + 研招网硕士专业目录发现”定位考 408 的院校，逐校官网核验招生目录、复试内容与最近两个招生年度（当前 2025、2026）录取情况。
- 录取只提取复试线、拟录取人数、分数区间等统计口径并给直接 URL；不复制含个人信息的完整拟录取名单。
- 插件无后台监控能力，不承诺自动提醒；每次调用重新核验并给出核验日期，离线时明确 `[待核验]`。

## 使用方法

### 在哪里使用

- **ChatGPT Desktop / Codex Desktop**：新建任务后直接提问即可，13 个 Skills 自动加载；也可在桌面设置中添加 GitHub marketplace 安装（见“安装”）。
- **新版 CLI / IDE**：安装完成后同样在新会话中生效。
- 学习层（Exa、Wolfram、Quizlet、Obsidian、Notion 等）取决于宿主是否提供对应工具；未连接时插件自动降级，不伪造结果。

### 一次完整学习怎么走

1. 新建任务，说明目标：报考院校/专业、考试科目（数学一/二、英语一/二、408、政治）、考试时间与每周可支配时间。
2. 先让官方核验员确认当前大纲、报名安排与院校信息，例如“查一下 2026 年 408 大纲和 XX 大学招生目录”。
3. 制定计划（`kaoyan-408-planner`）→ 展开为当天时段（`kaoyan-review-executor`）。
4. 学习与刷题：可要求先搜索真题来源，再逐题图文讲解；计算可用 Wolfram 独立核验。
5. 把错题或多次作答记录交给错题闭环，聚类错因并安排间隔复测。
6. 阶段末用进度快照做诊断；需要模考时生成冻结题面套卷，交卷后按 rubric 评分。
7. 需要长期记忆时配置 Obsidian 或绑定 Notion；其他学习层工具可用时自动调用。

### 常用问法

| 场景 | 示例问法 |
| --- | --- |
| 真题搜索 | “用 Exa 找 2024 数学二真题的公开来源” |
| 单题讲解 | “用图解讲一下这道 408 操作系统题” |
| 计算核验 | “用 Wolfram 核验这个极限结果” |
| 写作/阅读批改 | “批改这篇英语二作文，标出证据链” |
| 规划 | “按目标日期和每周 20 小时做 408 四科周计划” |
| 执行 | “今晚 90 分钟刷数学，帮我展开” |
| 诊断 | “按我粘贴的进度快照诊断风险和调整信号” |
| 错题闭环 | “这套卷错题都是同一类，帮我聚类并安排复测” |
| 模考 | “生成一张 408 操作系统章节测，交卷后评分复盘” |
| 官方核验 | “查 2026 年报名时间、XX 大学复试内容和近两年录取” |
| 闪卡/图谱/复习 | “生成 Quizlet 闪卡”“把这章做成知识图谱”“做一轮 Kahoot 复习” |

### 跨会话记忆

- 插件不保存任何数据；需要跨会话时，把上次输出的 `StudyProfile` / `ProgressSnapshot` / `ReviewQueue`（Schema 1.1 JSON）粘贴回来即可。
- 启用 Obsidian 或 Notion 后可自动写回，跨会话直接检索；未配置时每次都从会话内记录开始。

### 记忆控制

- “本次不记忆”“只读模式” → 本轮只读，不写入任何学习层。
- “关闭大脑” → 全局禁用 Obsidian 写入（运行配置脚本 `disable`）。
- “忘记/删除某项记忆” → 先定位具体记录，默认移入归档，不直接永久删除。

### 看懂输出标签与状态行

- 每次回答末尾的学习层状态行，例如 `Obsidian：已读取 3 条记忆；已更新当前进度`，表示本轮检索/写回状态。
- `[Obsidian记忆]`：来自本地 Vault 的历史内容，不代表当前官方事实。
- `[用户材料]`：你当前会话实际提供的题目、讲义或笔记。
- `[真题证据]`：可追溯的真题来源（科目、年度、题号、URL、核验状态）。
- `[原创练习]` / `[原创解析]`：插件生成，不冒充真题或官方答案。
- `[待核验]`：无法访问一手来源或信息不完整，不作为决策唯一依据。

## 13 个 Skills

## 连接的应用与学习层

插件可条件式连接 **14 个学习层**。学习层只负责检索与沉淀，不改变唯一主责 Skill；宿主提供对应工具时才启用，否则明确降级。每次回答末尾输出一行学习层状态，例如：

`Obsidian：已读取 3 条记忆；已更新当前进度。`

### 记忆与知识库层

| 应用 | 作用 | 启用条件 | 成功状态行 | 未连接降级 |
| --- | --- | --- | --- | --- |
| **Obsidian** | 本地长期记忆：学习档案、进度、错题队列、真题索引与可复用方法 | 本机配置 `.codex/kaoyan-408/obsidian-brain.json` 且宿主有本地文件权限 | `Obsidian：已读取 N 条记忆；已更新当前进度` | 继续会话回答并输出可复制的便携记录 |
| **Notion** | 远程知识库：一次绑定“408考研”主页后，在确认范围内增量同步真题索引与原创解析 | 宿主提供已授权的 Notion 工具 | `Notion：已同步 N 条记录` | 只读或本轮不记忆 |
| **GoodNotes** | 手写笔记记忆：检索笔记用于讲题与错题聚类，可增量沉淀便携记录 | 宿主提供 GoodNotes 工具，或用户导出 Markdown/PDF | `GoodNotes：已连接；已读取 N 条笔记` | 请用户导出相关笔记供本轮使用 |

### 课程与资料检索层

| 应用 | 作用 | 启用条件 | 成功状态行 | 未连接降级 |
| --- | --- | --- | --- | --- |
| **Udemy** | 检索用户已购课程、章节与讲义，映射 408 考点 | 宿主提供已授权的 Udemy 工具（浏览器控制或连接器） | `Udemy：已连接；已检索 N 门课程/章节` | 仅处理用户粘贴的课程链接/章节摘要 |
| **Sider Scholar** | 学术论文与扩展资料检索 | 宿主提供已授权的 Sider Scholar 工具 | `Sider Scholar：已连接；已检索 N 条资料` | 普通网页搜索或 `[待核验]` |
| **Exa** | 网页、论文与备考资料检索 | 宿主提供已授权的 Exa 搜索/读取工具 | `Exa：已连接；已检索 N 条资料` | 普通网页搜索或 `[待核验]` |

| **Ace Quiz Maker** | 按科目/章节/难度生成原创自测 | 宿主提供 Ace Quiz Maker 工具 | `Ace Quiz Maker：已连接；已生成 N 题章节测` | 插件原创章节测 |

| **Kahoot** | 互动选择题复习回合（游戏化） | 宿主提供 Kahoot 工具 | `Kahoot：已连接；已创建 N 题复习回合` | 会话内快问快答 |

### 学习层统一规则

- 只处理用户当前会话实际提供的材料，或用户有权访问且实际提供的文件；不补全、搜索或重建整套资料。
- 观察与推断分离：计划写 `planned`、推测错因标 `hypothesis`，只有复测证据满足才标掌握。
- 用户说“本次不记忆”“只读模式”时本轮禁止写入；“关闭大脑”时全局禁用。
- 写入前重新读取目标并合并，冲突保留双方内容并标记待整理。
- 不保存整段对话、凭据、身份信息、设备路径、搜索缓存或未授权材料。
- 官方事实必须保留机构、适用年度、发布日期、直接 URL 与核验日期；旧笔记不能替代当前核验。

## 安装

新版 Codex CLI/IDE 可添加仓库 marketplace 后安装：

```powershell
codex plugin marketplace add yq6666-66/408-codex-plugin --ref v2.3.0
codex plugin add kaoyan-408@kaoyan-408
```

也可克隆固定版本，在 ChatGPT Desktop 或 Codex Desktop 打开仓库并从 repo marketplace 安装：

```powershell
git clone --branch v2.3.0 --depth 1 https://github.com/yq6666-66/408-codex-plugin.git
```

跨平台安装器：

```powershell
python scripts/install_local.py --check
python scripts/install_local.py
```

退出码：`0` 成功；`1` 校验、命令或安装失败；`2` 当前 Codex 不支持插件命令，需要桌面端人工安装。只有实际成功才输出 `Installed kaoyan-408`。

## Obsidian 大脑

配置位置为 `.codex/kaoyan-408/obsidian-brain.json`（Schema 1.1），支持 `projectRoot` / `knowledgeRoot` / `pastPaperRoot`：

```powershell
python scripts/configure_obsidian_brain.py configure --vault <Vault绝对路径>
python scripts/configure_obsidian_brain.py check
```

新安装默认使用 `20-项目/408考研`、`30-知识/408考研`、`40-真题/408考研`。插件只保存学习档案、当前进度、错题队列、真题索引与可复用方法；不保存整段对话、私人敏感内容或未授权材料。旧 `kaoyan-22408` 配置可自动迁移，且不移动或删除既有私人笔记。

## Notion 大脑

首次写入时确认一个“408考研”主页或数据库，插件写入唯一标记 `kaoyan-408-brain:1.0`。之后只在该范围内自动搜索、去重和增量更新；多个标记、授权失败或目标不可访问时停止写入。

默认结构为 `00｜真题索引`、`01｜数学一`、`02｜数学二`、`03｜英语一`、`04｜英语二`、`05｜408`。写入后会重新读取验证；页面 ID 和工作区信息不会进入仓库或发布包。

用户说“本次不记忆”“只读模式”或“不要同步 Notion”时，本轮禁止 Notion 和 Obsidian 写入。
