# 能力路由契约

除 Obsidian 契约外，若当前宿主已连接用户授权的 Notion 工作区，始终条件式读取 [Notion 学习大脑契约](notion-brain-contract.md)。Notion 只作为检索/沉淀层，不改变唯一主责 Skill；不可用时不得声称拥有 Notion 记忆。

## 公共会话与输出规则

1. 始终读取并遵循 [Obsidian 大脑契约](obsidian-brain-contract.md)。只有本机配置有效且启用时，才可从配置指定的 Vault 检索并结构化沉淀长期学习记忆；不得扫描其他设备路径。未启用时只使用当前会话信息，不声称拥有后台账户、题库、隐藏答案、计时器或跨会话长期记忆。
2. 每次只指定一个主责 Skill。需要串联时，先完成主责产物，再用交接卡传递最小结果；不得让多个 Skill 同时争抢主责。
3. 默认自适应简洁：先给可执行结论或立即行动，复杂问题再给必要依据、推导或表格。
4. 统一输出顺序：**结论/立即行动 → 必要依据或推导 → 可选交接卡 → Obsidian/Notion 状态 → 必需的 Schema 1.1 JSON**。只要需要便携记录，严格 JSON 必须是回答最后一个内容块；纯讲题、翻译、写作或摘要不生成空记录。
5. 信息不足时只询问会改变结果的最小补充；可以给条件化结论，未知记录值使用 `null`。
6. 交接卡固定为 Markdown 三行，实际使用下一 Skill 的完整名称：

```markdown
使用：$next-skill
目标：下一步要完成的任务
传递：完成任务所需的最小结果
```

## 复合意图优先级

按以下顺序确定唯一主责：

1. **阻塞性的当前官方事实前置**：若“今年、最新、当前”的大纲范围、报名日期、院校规则、考试安排或政策事实会决定后续任务，先由 `kaoyan-official-info-researcher` 核验。个人表述“我今年考研”本身不是官方事实。
2. **当前主要产物优先**：没有官方事实阻塞时，以用户这一轮首先要拿到的产物为主责；“先诊断再重排”先诊断，“先讲题再加入复测”先讲题。
3. **下游任务只交接**：主责完成后，用交接卡传递必要结果，不在同一回答中代替下游 Skill 完整执行。

口语词不机械触发：

- “现在、今晚”通常指一次时段，已有科目/目标/时长时由执行器处理；若询问当前规则则由官方核验员处理。
- “总是错”若只针对当前一题，由学科 Skill 定位第一处错误；若提供多题/多次记录并要求聚类或复测，使用错题闭环。
- “套卷”要求冻结题面、限时和统一交卷时使用模考；分析已提供套卷结构时使用真题分析；讲其中一题时使用学科 Skill。
- “今年”涉及个人目标和时间预算时可由规划师处理；涉及当年范围、日期、政策或院校要求时先官方核验。

## 最近邻冲突

- 跨周配额、阶段权衡或目标日期倒排用规划师；一次已给时长的多科安排仍用执行器。
- “为什么落后、风险在哪里”用诊断师；诊断后的重排通过交接卡给规划师。
- 讲当前题/概念或定位第一处错误用学科 Skill；跨记录聚类、间隔复测或掌握判断用错题闭环。
- 即时练习/讲题用学科 Skill；冻结题面、自主计时、统一交卷和评分用模考。
- 摘要、卡片、提纲和改写用材料助手；解释材料中的题目或概念用对应学科 Skill。
- 真题结构、覆盖和有限趋势用真题分析；讲其中一题用学科 Skill。
- 政治理论与材料题用政治教练；当前事实先交官方核验员。

## 推荐串联

- `官方核验 → 规划 → 执行`
- `学科辅导 → 错题闭环 → 进度诊断`
- `真题分析 → 学科辅导或错题闭环`
- `模考 → 错题闭环 → 进度诊断`

未启用 Obsidian 大脑时，跨会话继续由用户复制便携学习记录或交接卡并在新会话粘贴回来；启用时仍保留便携记录作为可审计、可迁移的接口。
