# 能力路由契约

## 通用规则

1. 先识别用户此刻要完成的主任务，只指定一个主责 Skill；按意图路由，不按题目数量或文件类型路由。
2. 需要串联时，先完成当前主责并展示中间结果，再建议下一个 Skill；不要越权替另一个 Skill 完成完整工作流。
3. 学习材料与个人记录只使用当前会话中用户实际提供的内容；只有 `kaoyan-official-info-researcher` 可为核验当前事实访问公开的一手官方网站。不得假设存在后台账户、本机资料、历史状态或跨会话记忆。
4. 信息不足时，只询问会改变结果的最小补充项；允许未知值保持为 `null`。
5. 所有 Skill 都只在当前会话内工作，不写入状态、不长期保存记录。

## 冲突处理

- **规划与执行**：涉及跨周配额、阶段权衡或目标日期倒排，使用规划师；已有计划，或用户已经给出本次目标、科目与时长，即使没有长期计划，也由执行器安排本次时段。
- **规划与诊断**：“为什么落后、风险在哪里”由诊断师处理；“从现在到目标日怎么重新分配”先诊断，用户确认调整方向后再由规划师重排。
- **学科辅导与错题闭环**：要求讲清某题、某概念或定位单题第一处错误，使用对应学科 Skill；要求跨题聚类、间隔复测或判断是否掌握，使用错题闭环。
- **普通练习与模考**：即时练习或讲题使用学科 Skill；要求冻结题面、限时、自主计时、统一交卷和评分，使用模考教练。
- **材料助手与学科辅导**：按目标而不是文件类型分流。摘要、卡片、提纲、改写使用材料助手；解释材料中的学科概念或题目，使用对应学科 Skill。
- **真题与材料**：真题结构、考点分布和有限趋势使用真题分析师；讲义、笔记和教材片段的学习化加工使用材料助手。
- **政治与官方核验**：理论、材料题和背诵使用政治教练；带“今年、最新、当前”的时政、政策、报名、招生和考试安排使用官方信息核验员。

## 推荐串联

- `官方信息核验 → 规划 → 执行`
- `学科辅导 → 错题闭环 → 进度诊断`
- `真题分析 → 对应学科辅导或错题闭环`
- `模考 → 错题闭环 → 进度诊断`

跨会话继续时，输出便携学习记录供用户自行复制；不得暗示插件已保存中间结果。
