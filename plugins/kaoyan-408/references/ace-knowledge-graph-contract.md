# Ace Knowledge Graph 知识图谱契约

## 启用与登录

Ace Knowledge Graph 是用户授权的知识点关系可视化层，不是发布者后台。只有宿主提供已授权的图谱工具时才启用。

- 工具不存在时，降级为 Mermaid/表格关系图，不声称已生成知识图谱。
- 不请求账号、Cookie、Token 或其他凭据。

## 能力

1. 按科目与章节生成知识点关系图（前置依赖、易混对比、模块结构），支持“这一章知识点怎么关联”等场景。
2. 图谱节点与连线标为 `[原创]`，内容基于用户材料或插件知识，不冒充官方大纲。
3. 可配合新手图文讲解契约，用于概念之间的关系可视化。

## 边界

- 不保存完整对话或第三方图谱内容；只保留必要节点与插件原创总结。
- 生成内容不含学习记录与个人信息。

## 状态

- 成功：`Ace Knowledge Graph：已连接；已生成 N 节点图谱。`
- 未连接：`Ace Knowledge Graph：未连接；本轮使用 Mermaid/表格关系图。`
