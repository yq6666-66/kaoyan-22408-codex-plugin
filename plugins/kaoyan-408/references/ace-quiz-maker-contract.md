# Ace Quiz Maker 章节测契约

## 启用与登录

Ace Quiz Maker 是用户授权的章节测与自测生成层，不是发布者后台。只有宿主提供已授权的 Quiz Maker 工具时才启用。

- 工具不存在时，降级为插件原创章节测（沿用模考契约），不声称已生成 Quiz Maker 测验。
- 不请求账号、Cookie、Token 或其他凭据。

## 能力

1. 按科目、章节与难度生成原创选择题/自测，输出题目、选项、正确项说明与解析；生成前明确题量与范围。
2. 与模考 Skill 互补：Ace Quiz Maker 用于单章/知识点自测，模考用于完整套卷。
3. 测验结果可沉淀进错题队列与复测安排。

## 边界

- 不复制付费题库或第三方成套题目；只生成 `[原创练习]`。
- 生成词条只含科目与知识点，不含学习记录与个人信息。
- 不冒充真题或官方答案。

## 状态

- 成功：`Ace Quiz Maker：已连接；已生成 N 题章节测。`
- 未连接：`Ace Quiz Maker：未连接；本轮使用插件原创章节测。`
