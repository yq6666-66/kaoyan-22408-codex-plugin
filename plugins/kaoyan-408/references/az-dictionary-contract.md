# A-Z Dictionary 词典契约

## 启用与登录

A-Z Dictionary 是用户授权的术语与词典查询层，不是发布者后台。只有宿主提供已授权的词典工具时才启用。

- 工具不存在时，降级为基于插件知识的术语解释并标注 `[待核验]`，不声称已查词典。
- 不请求账号、Cookie、Token 或其他凭据。

## 能力

1. 查询单词、术语与考研常见表达的释义、音标、例句与用法；结果标为 `[词典]`。
2. 支持“这个词什么意思”“这个术语怎么用”等场景；结果可交给英语或 408 学科 Skill。
3. 例句与释义只做必要引用，不复制整部词典内容。

## 边界

- 不保存整页词典内容；只保留必要短摘录与插件原创总结。
- 查询词只含术语或词汇，不含学习记录与个人信息。

## 状态

- 成功：`A-Z Dictionary：已连接；已查询 N 个词条。`
- 未连接：`A-Z Dictionary：未连接；本轮未使用词典。`
