# GoodNotes 笔记记忆契约

## 启用与登录

GoodNotes 是用户授权的手写笔记记忆层，不是发布者后台。只有宿主提供 GoodNotes 工具时才直连；否则允许用户手动导出笔记为 Markdown 或 PDF 后在本会话处理，不猜测私有 `.goodnotes` 格式。

- 不请求账号、Cookie、Token 或其他凭据；不扫描本地 GoodNotes 数据目录。
- 用户说“本次不记忆”“只读模式”或“不要同步 GoodNotes”时，本轮只读。

## 能力

1. 按科目/章节检索用户笔记，把笔记内容标为 `[用户材料]`，用于讲题、错题聚类与复习。
2. 支持把便携记录增量沉淀为 GoodNotes 笔记；写入前重新读取并合并，冲突保留双方内容并标记待整理。
3. 笔记中出现的旧结论不替代当前官方事实或真题来源证明。

## 写入边界

- 只保存学习档案、进度、错因、复测安排、掌握证据和稳定方法。
- 不保存整段对话、凭据、身份信息、设备路径、未授权材料或第三方长篇内容。
- 计划只能写 `planned`，用户确认完成后才写 `completed`；推测错因标 `hypothesis`。

## 状态

- 成功：`GoodNotes：已连接；已读取 N 条笔记。`
- 未连接：`GoodNotes：未连接；请导出相关笔记供本轮使用。`
