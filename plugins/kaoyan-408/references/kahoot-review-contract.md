# Kahoot 互动复习契约

## 启用与登录

Kahoot 是用户授权的互动复习层，不是发布者后台。只有宿主提供已授权的 Kahoot 工具时才启用。

- 工具不存在时，降级为会话内快问快答或章节测，不声称已创建 Kahoot。
- 不请求账号、Cookie、Token 或其他凭据。

## 能力

1. 按知识点生成互动选择题与复习回合，支持“把这章做成 Kahoot 复习”等场景。
2. 题目标为 `[原创练习]`，正确项与解析随题提供。
3. 与 Ace Quiz Maker 互补：Kahoot 偏互动/游戏化复习，Quiz Maker 偏章节自测。

## 边界

- 不复制付费题库或第三方成套题目；只生成 `[原创练习]`。
- 生成内容不含学习记录与个人信息。
- 不冒充真题或官方答案。

## 状态

- 成功：`Kahoot：已连接；已创建 N 题复习回合。`
- 未连接：`Kahoot：未连接；本轮使用会话内快问快答。`
