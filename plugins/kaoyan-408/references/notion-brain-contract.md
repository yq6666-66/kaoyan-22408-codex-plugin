# Notion 学习大脑契约

## 启用与一次绑定

Notion 是用户授权的远程学习笔记层，不是发布者后台。只有宿主提供已授权的 Notion 搜索、读取、创建或更新工具时才启用。

首次写入必须由用户确认目标“408考研”主页或数据库。确认后在目标页保存唯一标记：

```text
kaoyan-408-brain:1.0
```

后续可自动搜索该标记并在确认范围内增量更新。规则如下：

- 没有标记：保持只读并请求一次绑定，不能按标题猜页面。
- 恰好一个标记：读取并验证页面后自动更新。
- 多个标记或目标不可访问：停止写入并请用户选择，不得任意覆盖。
- 页面 ID、数据库 ID 和工作区信息不得写入插件仓库、发布包或公开输出。
- 用户说“本次不记忆”“只读模式”或“不要同步 Notion”时，本轮只读。

## 默认结构

在已绑定主页下复用或创建编号化模块：`00｜真题索引`、`01｜数学一`、`02｜数学二`、`03｜英语一`、`04｜英语二`、`05｜408`。每科按 `paperYear` 建立试卷页，按题号维护来源、原创解析、图解源码、易错点、复测状态和相关知识链接。

不得为同一科目、年度和题号重复创建页面。用真题契约的 `dedupeKey` 搜索已有记录；命中后更新，未命中才创建。

## 每轮流程

可用工具名称可能表现为 `Notion:search`、`Notion:fetch`、`Notion:notion-create-pages` 和 `Notion:notion-update-page`。无窄过滤条件时搜索使用 `filters: {}`；具体参数始终以当前宿主实际暴露的工具 Schema 为准。

1. 当前主责 Skill 不变；Notion 只检索和沉淀。
2. 每次搜索只使用一个明确字面查询；没有过滤条件时传空过滤对象。只把 Notion 页面、数据库或数据源 ID 交给读取工具，外部连接源 URL 不得作为页面 ID。
3. 先搜索插件标记与主题，再读取完整目标页。真题记录同时读取对应科目、年度和题号页。
4. 写入前重新读取。创建页时必须有明确 `parent`；更新页时使用宿主实际支持的 `update_content`/`update_properties` 结构，并用精确 `old_str`/完整 `new_str` 替换，不发明 `insert_content` 等字段。
5. 写后再次读取，验证父子层级、标题、`dedupeKey` 和正文；未验证不得声称已保存。
6. 工具不存在、授权失效或写入失败时不重试不存在的工具；继续学习回答，并输出可复制 Markdown 增量。

## 写入内容

- 保存 `[真题证据]` 元数据、合法来源链接、许可判断、必要短摘录、用户作答、`[原创解析]`、可编辑图解源码、已确认错因和复测安排。
- 只有 `storagePolicy=full-text` 才能保存全文；否则固定为索引模式。
- 不保存整段对话、密钥、Cookie、身份信息、设备路径、搜索缓存、未授权试卷或第三方长篇解析。
- 观察与推断分离；新计划只能写 `planned`，假设错因标 `hypothesis`，用户确认完成后才写 `completed`。
- 当前官方事实必须保留机构、适用年度、发布日期、直接 URL 和绝对核验日期；旧 Notion 笔记不能替代当前核验。

## 状态

- 成功：`Notion：已检索 N 条相关笔记；已验证更新 <页面标题>。`
- 只读：`Notion：已检索 N 条相关笔记；本轮只读，无写入。`
- 未绑定：`Notion：已连接但未绑定 408考研主页；本轮无写入。`
- 降级：`Notion：未连接；仅使用当前会话及其他已启用记忆层。`
