# Quizlet 闪卡记忆契约

## 启用与登录

Quizlet 是用户授权的闪卡记忆层，不是发布者后台。只有宿主提供已授权的 Quizlet 工具时才启用。

- 工具不存在或未登录时，降级为会话内自制闪卡与便携记录，不声称已同步 Quizlet。
- 不请求账号、Cookie、Token 或其他凭据；登录状态由用户自己的宿主会话管理。

## 能力

1. 按知识点生成或检索闪卡组，支持“把今天错题做成闪卡”“复习这章概念”等场景。
2. 闪卡内容以 `[原创练习]` 或 `[用户材料]` 标注，与真题、官方答案分离。
3. 便携记录中的知识点与复测安排可转成闪卡；学习结果沉淀遵循证据契约。

## 边界

- 不复制付费题库或第三方完整闪卡组；只生成插件原创闪卡或整理用户材料。
- 查询与生成词条只含知识点，不含学习记录与个人信息。
- 生成前明确范围与数量，不批量重建整套资料。

## 状态

- 成功：`Quizlet：已连接；已生成/检索 N 张闪卡。`
- 未连接：`Quizlet：未连接；本轮使用会话内自制闪卡。`
