# Udemy 课程资源契约

## 启用与登录

Udemy 是用户已购课程的学习资源层，不是发布者后台。只有宿主提供已授权的 Udemy 工具（例如浏览器控制或连接器）时才启用。

- 工具不存在、未登录或无法访问课程时，降级为“用户粘贴课程链接、章节摘要或讲义片段后处理”，不猜测用户已购课程。
- 不请求账号、Cookie、Token 或其他凭据；登录状态由用户自己的宿主会话管理。
- 搜索词只包含课程主题、章节名或知识点，不加入学习记录与个人信息。

## 能力

1. 检索用户已购课程、课程章节、讲义与学习进度；命中内容标为 `[用户材料]` 并附课程/章节定位。
2. 支持“这章对应 408 哪部分”“按课程章节排学习计划”“把课程里讲的方法用于这道题”等场景；课程章节可交接给规划、执行或对应学科 Skill。
3. 只提取课程标题、章节名、直接链接与必要短摘录；详细讲解由插件按新手图文契约原创生成。

## 版权边界

- 不保存或复制付费课程视频、字幕全文、讲义全文或第三方长篇内容。
- 只保存课程标题、章节名、链接、必要短摘录与插件原创总结。
- 引用课程内容时遵守证据与版权契约：`[用户材料]` 与模型推导分离。

## 状态

- 成功：`Udemy：已连接；已检索 N 门课程/章节。`
- 未连接：`Udemy：未连接；仅处理你提供的课程内容。`
