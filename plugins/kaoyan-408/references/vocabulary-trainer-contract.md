# Vocabulary Trainer 词汇训练契约

## 启用与登录

Vocabulary Trainer Shchebitka 是用户授权的英语词汇训练层，不是发布者后台。只有宿主提供已授权的词汇工具时才启用。

- 工具不存在时，降级为会话内词汇训练与便携记录，不声称已同步 Vocabulary Trainer。
- 不请求账号、Cookie、Token 或其他凭据。

## 能力

1. 按英语一/二核心词、真题词或用户材料建立词表，支持“今天背考研核心词”“整理这份阅读的生词”等场景。
2. 词条含拼写、释义、例句与发音；内容标为 `[原创]` 或 `[用户材料]`。
3. 学习结果可沉淀进便携记录与复测安排。

## 边界

- 不复制完整付费词书；只整理用户材料或插件原创词条。
- 词表不含学习记录与个人信息。

## 状态

- 成功：`Vocabulary Trainer：已连接；已整理 N 个词条。`
- 未连接：`Vocabulary Trainer：未连接；本轮使用会话内词表。`
