# Wolfram 计算核验契约

## 启用与登录

Wolfram 是用户授权的计算与公式核验层，不是发布者后台。只有宿主提供已授权的 Wolfram 工具（WolframAlpha、Wolfram Language 或等效能力）时才启用。

- 工具不存在或不可用时，降级为人工推导与复核，不声称已使用 Wolfram。
- 不请求账号、Cookie、Token 或其他凭据；登录状态由用户自己的宿主会话管理。

## 能力

1. 对数学公式、数值、符号计算与单位换算执行独立核验；结果作为 `[Wolfram计算]` 标注并与模型推导分离。
2. 支持“验算这道题的结果”“比较两个公式”“换算单位”等场景；结果可交给数学或 408 学科 Skill 使用。
3. 不把 Wolfram 输出当作真题答案或官方事实，只作为计算辅助。

## 边界

- 不保存完整计算过程或第三方内容；只保存必要结果与插件原创总结。
- 计算结果有歧义或与教材方法冲突时，并列给出并标注差异。
- 搜索词与输入只含题目相关数值与公式，不含学习记录与个人信息。

## 状态

- 成功：`Wolfram：已连接；已完成 N 项计算核验。`
- 未连接：`Wolfram：未连接；本轮使用人工推导与复核。`
