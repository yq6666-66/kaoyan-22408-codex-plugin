# 公开提交检查清单

- [ ] GitHub 仓库公开，`v1.0.0` Release 与 SHA-256 已发布。
- [ ] 网站、支持、隐私政策和使用条款 URL 可匿名访问。
- [ ] OpenAI Platform 发布身份已验证。
- [ ] 提交者具有 Apps Management 写权限。
- [ ] 上传的 Skill 文件树与 GitHub Release 完全一致。
- [ ] 上传正式 SVG Logo；Skills-only 插件不上传界面截图。
- [ ] 填入 `test-cases.json` 中恰好 5 个正向和 3 个负向测试。
- [ ] Release notes 使用 `release-notes.md`，无需评审账号或凭据。
- [ ] 地区选择门户当时支持的全部可用地区。
- [ ] 最终预览确认无 App、MCP、工具、认证或服务器字段。
- [ ] 提交审核；审核通过后再由发布者执行公开发布。

若身份验证或 Apps Management 权限不满足，停止在 GitHub Release 与本地验证阶段，不提交公开目录。
